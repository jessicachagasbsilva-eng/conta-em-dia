# Conta em Dia

App gratuito de finanças pessoais para sair das dívidas: salário com INSS e IR 2026, leitura de holerite, contas fixas, gastos do dia, importação de extrato (OFX/CSV) e plano de quitação das dívidas.

Os dados ficam só no aparelho de quem usa (armazenamento local do navegador). Pode ser instalado no celular pela opção "Adicionar à tela inicial".
